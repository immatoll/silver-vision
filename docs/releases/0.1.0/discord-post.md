# SilverVision — An In-Game Overlay for Your Frontier dApps

SilverVision is a desktop overlay for EVE Frontier that lets you browse and run dApps as movable windows on top of the game — similar to Overwolf, but built specifically for the frontier ecosystem.

## What it does

- **A dApp catalog** — browse a curated catalog of webapps and suggested EVE Frontier dApps, and launch any of them as their own window straight from an app store-style menu.
- **Overlay modes** — full transparency, mouse-over transparency, or always-on-top, so you can keep dApps visible and usable without alt-tabbing out of the game.
- **Window management** — each launched app runs in its own titled, movable window with pinning support.
- **Settings panel** — quick access to app-level configuration from an overlay panel.
- **Built-in wallet** — bundles a wallet browser extension for connecting and signing transactions directly from inside the overlay, no separate browser needed.
- **Bring your own dApp** — the catalog isn't locked down: write and host your own small webapp sized for a compact window, and it'll run in SilverVision like any other entry.

## Why it matters

Most EVE Frontier dApps live in a browser tab you have to alt-tab to, breaking immersion while flying or managing structures. SilverVision keeps them one click away, on top of the game, in their own windows — closer to how Overwolf handles overlays for traditional games.

## Getting started

Download the installer from the release below, run it, and use the app store menu to browse the catalog and launch a dApp.

**Release (v0.1.0):** https://github.com/immatoll/silver-vision/releases/tag/v.0.1.0

## Known limitations

This is an early preview — the wallet integration is still work in progress. Signing transactions itself works, but the UI doesn't always refresh reliably after certain actions (e.g. after logging in), so a manual reload may occasionally be needed. Expect other rough edges too.
